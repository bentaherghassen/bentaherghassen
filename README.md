# 💫 $ Whoami :
Hi, I’m Ghassen Ben Taher 👋<br>I’m a Python Backend Developer from Tunisia with a passion for building scalable web applications, AI-powered solutions, and accessible digital experiences.<br>I primarily work with Python, Django, Flask, and modern web technologies to design clean architectures, build RESTful APIs, automate workflows, and create applications that solve real-world problems.<br>I believe great software is more than just code—it’s software that is reliable, maintainable, secure, and accessible to everyone.<br><br>$ accessibility <br><br>Accessibility isn’t just something I build—it’s something I live every day.<br>I am a blind software developer, and my entire development workflow is powered by assistive technologies, including screen readers such as NVDA on Windows and TalkBack on Android.<br>This experience has given me a unique perspective on software engineering. This never changes my commitment to delivering high-quality, professional results.<br>I also enjoy exploring artificial intelligence, backend architecture, developer tools, automation, and creating content that helps others learn.<br><br>$ let’s_connect <br><br>I’m always interested in collaborating on meaningful projects, contributing to open-source software, and working with teams that value quality, accessibility, and continuous learning.
